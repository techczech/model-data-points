Purpose

To decide whether a new OCR model is worth adding to a PDF-to-Markdown workflow for academic papers, which already uses Docling by default and MinerU for maths-heavy papers.

Context

Ten academic papers, 174 pages: three two-column journal papers, two table-heavy papers, two maths-heavy papers, one scanned 1967 book chapter, one 66-page report and one Spanish-language paper. All runs were on an NVIDIA DGX Spark (GB10, 128 GB unified memory), one tool at a time. Unlimited-OCR 2 is a recent model from Baidu that reads page images directly.

Method

Each paper was converted to Markdown by each tool. Wall-clock time was recorded per paper. The Transformers route was started on the first papers and stopped when it proved too slow. Text was compared with the PDF's own text layer (word error rate), every number in each output was checked against the numbers in the text layer, and tables were counted. The scan was compared with OCRmyPDF output instead.

Results

Docling took 3.5 minutes for all 10 papers, Unlimited-OCR 2 on SGLang 31 minutes and MinerU 62 minutes, with no accuracy advantage for either slower tool on born-digital papers.

Scanned chapter. Against OCRmyPDF as baseline, Unlimited-OCR 2 (19.3%) and MinerU (17.6%) differed far less than Docling (37.5%).

Caveats

  • One machine, one set of 10 papers, one run each (n=1).
  • The word error rate is dominated by reading order (headers, footnotes, figure text placed differently), so it shows the tools as roughly equal rather than measuring misread words.
  • Most numbers not found in the text layer are page numbers, table cells or formatting differences, not misreadings. One real misreading was found in Unlimited-OCR 2 output: a caption's 75% written as 55%.
  • One 66-page report accounts for most absent numbers in every tool (200 to 261).
  • SGLang times exclude about 1 min 45 s of server start-up; the server held about 61 GB of GPU memory.
  • Table layout quality was not judged by eye.

What this suggests

For born-digital academic PDFs, Docling was about nine times faster than Unlimited-OCR 2 and as accurate on these measures, so the new model was not adopted. Unlimited-OCR 2 may be worth a look for scanned pages, and only through a serving engine such as SGLang: through Transformers it was 5 to 10 times slower again.
